# 3D Space Flight Game

## 概要

DxLibとC++を用いて制作している3D宇宙フライトゲームです。

物理演算や3D姿勢制御を用い、
宇宙空間を自由に飛行できるシステムを個人開発しています。

## 制作目的

「ただ動くゲーム」ではなく、
物理演算や3D空間の回転制御が
“なぜその仕組みで動くのか”
を理解したいと思い制作を始めました。

## 技術的に工夫した点

### クォータニオンによる姿勢制御

最初はオイラー角で実装していましたが、
機体が真上を向くとジンバルロックが発生し、
カメラ挙動が破綻する問題がありました。

そのためクォータニオンを導入し、
空間全体を回転させる形へロジックを書き換えることで、
滑らかな3D姿勢制御を実現しました。

### オブジェクト指向設計

CharacterBaseクラスを作成し、
Player / Enemy / Bullet に共通ルールを継承させています。

これにより、

* 可読性向上
* 管理コスト削減
* バグ発生率低減

を実現しました。

## AI活用について

AIを開発補助として活用していますが、
コードをそのまま利用するのではなく、
必ずロジックの意図を理解してから組み込むことを徹底しています。
